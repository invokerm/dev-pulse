# ⚡ DevPulse

> A modern, real-time GitHub analytics dashboard built to inspect profiles, analyze repository language metrics, and visualize developer activity cleanly.

![Project Preview](https://img.shields.io/badge/status-active-success) ![License](https://img.shields.io/badge/license-MIT-blue)

## 🚀 Features
- **Profile Overview:** Real-time fetching of user metrics (followers, public repositories, bio).
- **Language Distribution:** Dynamic analytics charts tracking top programming languages across public repos using Recharts.
- **Repository Explorer:** Instant view of recent repositories with direct links and descriptions.
- **Modern UI/UX:** Styled completely with Tailwind CSS featuring a sleek, responsive dark-mode glassmorphism interface.

## 🛠️ Tech Stack
- **Frontend:** React.js (Vite)
- **Styling:** Tailwind CSS
- **Data Visualization:** Recharts
- **Icons:** Lucide React
- **API:** GitHub REST API
